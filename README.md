# Regime-Aware, News-Driven Quantitative Research System

A multidisciplinary quantitative research system designed to evaluate whether financial-news sentiment and company-specific financial results improve out-of-sample stock-direction prediction across different hidden market regimes.

## Setup

1. Create a virtual environment:
   `python -m venv .venv`
2. Activate it:
   `source .venv/bin/activate`
3. Install dependencies:
   `pip install -e .[dev]`
4. Run tests:
   `pytest`
